# IEEE 802.11 Fundamentals

## 1. Overview of 802.11 Architecture
The IEEE 802.11 standard defines the MAC and PHY layers for wireless local area networks (WLAN). Unlike wired Ethernet (CSMA/CD), 802.11 utilizes **CSMA/CA (Carrier Sense Multiple Access with Collision Avoidance)** to manage shared medium access.

### Standard Evolution
| Standard | Common Name | Frequency | Max Rate | Key Tech |
| :--- | :--- | :--- | :--- | :--- |
| **802.11n** | Wi-Fi 4 | 2.4 / 5 GHz | 600 Mbps | MIMO |
| **802.11ac** | Wi-Fi 5 | 5 GHz | 3.46 Gbps | MU-MIMO |
| **802.11ax** | Wi-Fi 6 | 2.4 / 5 / 6 GHz | 9.6 Gbps | OFDMA |

## 2. Frame Types and Structure
Every 802.11 frame contains a **Frame Control Field**. The `Type` and `Subtype` bits determine the function of the frame.

### 2.1 The Three Main Categories (wlan.fc.type)
- **Type 0 (00) - Management Frames**: Used to establish and maintain the connection between a Station (STA) and an Access Point (AP).
- **Type 1 (01) - Control Frames**: Assist with the delivery of data frames (e.g., ACK, RTS/CTS).
- **Type 2 (10) - Data Frames**: Carry the actual higher-layer protocols (IP, TCP/UDP).

### 2.2 Critical Management Subtypes (wlan.fc.type_subtype)
| Subtype | Name | Description |
| :--- | :--- | :--- |
| **0** | Association Request | Client requests to join a BSSID. |
| **1** | Association Response | AP accepts/rejects the association. |
| **8** | Beacon | AP broadcasts its presence and capabilities. |
| **11** | Authentication | Client proves identity to the AP. |
| **12** (0x0C) | **Deauthentication** | Termination of an existing connection. |

## 3. Vulnerability: Deauthentication Attacks
Traditional 802.11 management frames are sent in the clear and are unauthenticated. This allows an attacker to spoof the MAC address of an AP or Client to forcibly disconnect them.

### Attack Objectives
1. **WPA Handshake Capture**: Forcing a client to reconnect to sniff the 4-way handshake for offline cracking.
2. **Denial of Service (DoS)**: Persistently flooding Deauth frames to keep a target offline.
3. **Evil Twin Redirection**: Kicking a user off a legitimate AP so they connect to a malicious Rogue AP.

### Reason Codes (wlan.fixed.reason_code)
Reason codes explain why a disconnection occurred. They are crucial for SOC attribution.
- **Code 1 (Unspecified)**: Generic disconnection.
- **Code 4 (Inactivity)**: **Normal behavior**. Client timed out.
- **Code 6/7**: **Highly Suspicious**. Standard tools like `aireplay-ng` often default to these codes when a non-associated STA sends a deauth frame.
