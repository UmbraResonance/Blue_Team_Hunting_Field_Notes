# Windows Shell Namespace & User Tracking

> **Core Concept:** The Windows Explorer shell heavily tracks user interactions to optimize the UI experience, such as remembering folder views and recent files.
> **Blue Team Impact:** Shell artifacts reconstruct interactive user sessions, proving **Data Staging (T1074)**, folder browsing, and physical/RDP access.

---

## 1. Technical Architecture

The Windows Shell creates a virtual namespace (folders, control panel items, network shares) mapped to the physical file system. To maintain user preferences across reboots, it silently writes telemetry to hidden system files.

### **1.1 LNK Files (Shortcuts)**
* **Mechanism:** Automatically created by the OS in the `Recent` folder when a user opens a file.
* **Forensic Value:** Contains the target file's MAC times, original volume serial number, and network share details (MAC address of the hosting machine).
* **Location:** `C:\Users\<User>\AppData\Roaming\Microsoft\Windows\Recent`

### **1.2 JumpLists**
* **Mechanism:** Backs the "Recent Items" feature seen when right-clicking taskbar icons.
* **Structures:** * `AutomaticDestinations` (Created by the OS).
  * `CustomDestinations` (Created by the application).
* **Forensic Value:** Proves specific files were accessed via specific applications (e.g., viewing a malicious document via Word).

### **1.3 ShellBags**
* **Mechanism:** Records UI preferences (window size, icon view) every time a user navigates into a directory via Explorer.
* **Forensic Value:** Proves directory traversal. Critically, ShellBag entries persist even after the target folder is deleted.
* **Location:** `UsrClass.dat` and `NTUSER.DAT`.

---

## 2. Adversary TTPs

### **Scenario A: Proving Interactive RDP Access (T1021.001)**
* **Mechanism:** An attacker compromises an account and logs in via RDP. They manually browse to `C:\Financial_Data` and open `passwords.txt`.
* **Detection:** Even if the attacker deletes the file and clears the Event Logs, ShellBags will prove they navigated to the folder, and LNK/JumpLists will prove they opened the text file.

### **Scenario B: Data Exfiltration Staging (T1074)**
* **Mechanism:** Attackers create a hidden staging folder, move sensitive files into it, and zip them.
* **Detection:** ShellBag analysis will reveal the creation and access of the temporary staging directory.

## 3. Detection Engineering (SOC Red Flags)

| Red Flag | Description | Correlation |
| :--- | :--- | :--- |
| **Rogue Directory Browsing** | ShellBag entries showing navigation to sensitive admin shares or staging directories (`C:\PerfLogs`). | Parse via `SBECmd` per [[6.02_Windows_DFIR_Master_Notes]]. |
| **External Drive Access** | LNK files referencing Volume Serial Numbers that belong to unauthorized USB drives. | Correlate with Event 4663 or Plug-and-Play logs. |
| **Deleted Asset Proof** | A folder does not exist on disk, but has a valid, recently accessed ShellBag entry. | Check USN Journal (`MFTECmd`) for deletion events. |
