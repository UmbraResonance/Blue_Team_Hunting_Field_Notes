# WMI & CIM Repository Architecture

> **Core Concept:** WMI (Windows Management Instrumentation) is the infrastructure for management data and operations on Windows operating systems, heavily utilizing the CIM (Common Information Model) repository.
> **Blue Team Impact:** WMI is a primary vector for **Living off the Land (LoL)**, offering stealthy execution, remote lateral movement, and fileless persistence.

---

## 1. Technical Architecture

WMI operates as a sophisticated client-server architecture built into the OS.

### **1.1 Core Components**
* **WMI Service (`Winmgmt`)**: The core engine routing requests. Runs within `svchost.exe`.
* **WMI Providers (`WmiPrvSE.exe`)**: The "workers" that actually interface with the OS to retrieve data or execute commands (e.g., the `Win32_Process` provider).
* **CIM Repository**: The central database (`C:\Windows\System32\wbem\Repository\OBJECTS.DATA`) storing class definitions and persistent WMI objects.

### **1.2 WMI Eventing (The Persistence Mechanism)**
WMI can act autonomously based on triggers, using three components:
1. **Event Filter**: The condition (e.g., "Trigger when system uptime reaches 5 minutes").
2. **Event Consumer**: The action to take (e.g., "Run this base64 encoded PowerShell script").
3. **Filter-To-Consumer Binding**: The bridge connecting the Filter to the Consumer.

## 2. Adversary TTPs

### **Scenario A: Fileless Persistence (T1546.003)**
* **Mechanism:** Attackers inject a malicious payload into a `CommandLineEventConsumer`. They bind it to an `__InstanceCreationEvent` filter monitoring for a common process launch (e.g., `notepad.exe`).
* **Detection:** The payload lives entirely within the CIM repository, not as a standalone file, evading traditional antivirus file scans.

### **Scenario B: Lateral Movement (T1047)**
* **Mechanism:** Using `wmic.exe` or `Invoke-WmiMethod` to spawn a process on a remote machine via the `Win32_Process` class.
* **Detection:** Generates network traffic over RPC/DCOM (Port 135/High Ports) and results in process creation by `WmiPrvSE.exe` on the target.
