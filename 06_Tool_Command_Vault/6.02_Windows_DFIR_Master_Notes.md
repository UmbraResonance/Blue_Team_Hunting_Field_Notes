## Master Evidence & Tool Map

This table serves as a strategic reference for mapping forensic goals to specific artifacts and tools.

| Category | Forensic Value (Evidence) | Primary Tools | Analysis Phase |
| :--- | :--- | :--- | :--- |
| **Network Connections** | Identify active socket communication, remote IPs, and DNS resolutions. | netstat, Get-NetTCPConnection, ipconfig | Phase 1: Live |
| **Program Execution** | Prove binary execution history, run counts, and execution timestamps. | PECmd (Prefetch), AppCompatCacheParser (ShimCache) | Phase 2: Disk |
| **File System Metadata** | Track file creation, deletion, renames, and timestomping within $MFT. | MFTECmd ($MFT / $J) | Phase 2: Disk |
| **Persistence Mechanisms** | Audit system services, scheduled tasks, and Registry auto-run entries. | schtasks, RegRipper (rip.exe), Get-Service | Phase 1 & 2 |
| **User Activity Artifacts** | Evidence of folder navigation history and recent file access. | SBECmd, JLECmd, LECmd | Phase 2: Disk |
| **Binary Metadata** | Retrieve SHA1 hashes from executed binaries for threat intelligence pivoting. | AmcacheParser | Phase 2: Disk |
| **Event Log Analysis** | Analyze structured system/security logs for anomalous sequences. | Get-WinEvent, Chainsaw, EQL | Phase 3: Logs |
| **Triage & Collection** | Automated high-speed acquisition of critical forensic data. | KAPE | Phase 2: Disk |

## DFIR Investigative Workflow

Follow these steps to maintain data integrity and maximize evidence recovery.

1. **Step 1: Volatile Data Collection (Live Response)** Prioritize memory-resident data, active network connections, and running processes before shutting down or isolating the host.
2. **Step 2: Rapid Triage Collection** Use KAPE to pull critical disk artifacts ($MFT, Registry, Logs) to allow for offline analysis without full disk imaging.
3. **Step 3: Artifact Deep-Dive** Parse the collected artifacts using EZ Tools to reconstruct user activity and program execution history.
4. **Step 4: Timeline Correlation & Hunting** Merge parsed CSVs into Timeline Explorer and perform targeted log hunting to build the complete attack narrative.

## Phase 1: Windows Live Analysis (Triage)

**Focus:** Live response via RDP/Shell on a running system.
**Goal:** Identify "low hanging fruit" (persistence, active C2) *before* full forensic acquisition.

### 1.1 Network Connections
*Goal: Find the malware beaconing home.*

**Basic (CMD): Quick check for established connections.**

```cmd
netstat -ano | findstr "ESTABLISHED"
# Action: Note the PID (Process ID) on the far right.
```

**Advanced (PowerShell): Correlate connection to Process Name immediately.**

```powershell
# List all TCP connections with owning process info
Get-NetTCPConnection | Select-Object LocalAddress, LocalPort, RemoteAddress, RemotePort, State, OwningProcess, @{Name="Process";Expression={(Get-Process -Id $_.OwningProcess).ProcessName}} | Format-Table -AutoSize
```

**DNS Cache: What domains has this machine resolved recently?**

```cmd
ipconfig /displaydns | findstr "Record"
```

### 1.2 Process Analysis
*Goal: Find the malware running in memory.*

**Basic (CMD): Verbose list to see the user running the process.**

```cmd
tasklist /v
# Look for: "svchost.exe" running as a normal User (Should be SYSTEM/NETWORK SERVICE).
```

**Advanced (PowerShell): Calculate Hash of running processes for VirusTotal check.**

```powershell
Get-WmiObject Win32_Process | Select-Object Name, CommandLine | Format-List
```

**Process Command Lines: Spot the arguments (e.g., base64 strings).**

```powershell
Get-WmiObject Win32_Process | Select-Object Name, CommandLine | Format-List
```

### 1.3 User & Account Anomalies
*Goal: Find backdoors created by the attacker.*

**Basic (CMD):**

```cmd
# List users
net user
# Check Local Admins (Did they add themselves?)
net localgroup administrators
```

**Advanced (PowerShell):**

```powershell
# Check for users with passwords set recently (if AD module not available, check LastLogon)
Get-LocalUser | Select-Object Name, Enabled, LastLogon, PasswordLastSet
# Check who is logged in RIGHT NOW
qwinsta
```

### 1.4 Persistence Mechanisms
*Goal: Find how the malware survives a reboot.*

**Scheduled Tasks:**

```cmd
schtasks /query /fo LIST /v | findstr "TaskName Status"
# Look for random names or tasks running from \Temp
```

**Services: Filter out the noise (Microsoft signed services).**

```powershell
# List 'Running' services that are NOT from "C:\Windows\" (High noise filter, but effective)
Get-WmiObject Win32_Service | Where-Object { $_.State -eq 'Running' -and $_.PathName -notlike "*C:\Windows\*" } | Select-Object Name, DisplayName, PathName, StartMode
```

**Registry Run Keys:**

```cmd
reg query HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Run
reg query HKCU\Software\Microsoft\Windows\CurrentVersion\Run
```

### 1.5 Event Log Automation (DeepBlueCLI)
**Run against LIVE logs:**

```powershell
# Analyze Security Log (Attacks, Logins)
.\DeepBlue.ps1 -log security
# Analyze System Log (Service creation)
.\DeepBlue.ps1 -log system
```

### 1.6 One-Liner Collection Script (Panic Button)

```powershell
# Create an evidence folder
$dest = "C:\Evidence_$(get-date -f yyyyMMdd_HHmm)"; New-Item -ItemType Directory -Force -Path $dest
# 1. Export Process List
Get-Process | Select-Object * | Export-Csv "$dest\processes.csv" -NoTypeInformation
# 2. Export Network Connections
Get-NetTCPConnection | Export-Csv "$dest\network.csv" -NoTypeInformation
# 3. Export Services
Get-Service | Export-Csv "$dest\services.csv" -NoTypeInformation
# 4. Zip it up (Windows 10+)
Compress-Archive -Path $dest -DestinationPath "$dest.zip"
Write-Host "Evidence collected at $dest.zip" -ForegroundColor Green
```

### 1.7 File Metadata & Alternate Data Streams (ADS)
**Extract Zone.Identifier (MotW): Files downloaded from the Internet Zone are tagged with ZoneId=3.**

```powershell
Get-Item * -Stream Zone.Identifier -ErrorAction SilentlyContinue

**Read the contents of the Zone.Identifier (Extract Source URL):**
Get-Content "<TARGET_FILE_NAME>" -Stream Zone.Identifier -ErrorAction SilentlyContinue
```

## Phase 2: Windows Disk Artifact Analysis

**Focus:** Parsing disk artifacts (Prefetch, MFT, Registry, Browsers) for evidence.
**Tools:** EZ Tools (Zimmerman), CAPE, Hindsight, bstrings, RegRipper.

### 2.1 KAPE (Kroll Artifact Parser and Extractor)
**Collect & Process:**

```powershell
kape.exe --tsource C: --target KapeTriage --tdest C:\Temp\KapeOut --vhdx KapeTriage_Image --vss --module EZParser --mdest C:\Temp\KapeParsed --bflush
```

### 2.2 Eric Zimmerman Tools (EZ Tools)

#### Prefetch (PECmd)
*Evidence: Prove execution & verify execution time.*

**Parse a single file (Target specific malware):**

```powershell
PECmd.exe -f "<PATH_TO_MALICIOUS_FILE.pf>"
# Default Prefetch files are under C:\Windows\Prefetch in living system.
```

**Parse WHOLE directory to CSV (The Standard Move):**

```powershell
PECmd.exe -d "<DIRECTORY_WITH_PREFETCH_FILES>" -csv "C:\Temp\Output" -q
# Key Output: RunCount, LastRun (UTC), ExecutablePath.
```

#### Windows Event Log Parser (EvtxECmd)
**Sync latest maps (Perform before any analysis):**

```powershell
.\EvtxECmd.exe --sync
```

**Parse EVTX to CSV (The Standard Move):**

```powershell
.\EvtxECmd.exe -f "<PATH_TO_EVTX_FILE>" --csv "<OUTPUT_DIRECTORY>" --csvf <OUTPUT_FILENAME.csv>
```

#### MFT (MFTECmd)
**Parse $MFT to CSV:**

```powershell
MFTECmd.exe -f "<PATH_TO_$MFT_FILE>" -csv "<OUTPUT_DIRECTORY>" --csvf <OUTPUT_FILENAME.csv>
# Tip: Filter output CSV for .exe, .ps1, or Zone.Identifier (ADS).
```

#### USN Journal (MFTECmd)
**Parse USN Journal ($J) to CSV:**

```powershell
MFTECmd.exe -f "<PATH_TO_$EXTEND_$J>" --csv "<OUTPUT_DIRECTORY>" --csvf <OUTPUT_FILENAME.csv>
```

#### JumpLists (JLECmd)

```powershell
JLECmd.exe -d "<PATH_TO_USER_AUTOMATICDESTINATIONS>" --csv "<OUTPUT_DIRECTORY>" -q
# Path: C:\Users\<USERNAME>\AppData\Roaming\Microsoft\Windows\Recent\AutomaticDestinations
```

#### LNK Files (LECmd)

```powershell
LECmd.exe -d "<PATH_TO_USER_RECENT>" --csv "<OUTPUT_DIRECTORY>" -q
# Path: C:\Users\<USERNAME>\AppData\Roaming\Microsoft\Windows\Recent
```

#### ShellBags (SBECmd)

```powershell
SBECmd.exe -d "<DIRECTORY_WITH_USRCLASS.DAT>" --csv "<OUTPUT_DIRECTORY>" -q
# Path: C:\Users\<USERNAME>\AppData\Local\Microsoft\Windows\UsrClass.dat
```

#### ShimCache (AppCompatCacheParser)

```powershell
AppCompatCacheParser.exe --csv "<OUTPUT_DIRECTORY>" -f "<PATH_TO_SYSTEM_HIVE>"
```

#### Amcache (AmcacheParser)

```powershell
AmcacheParser.exe --csv "<OUTPUT_DIRECTORY>" -f "<PATH_TO_AMCACHE_HIVE>" -i on
# Forensic Value (Fact): Amcache stores SHA1 hash, critical for threat intel pivoting.
```

#### Registry Transaction Log Replayer (rla.exe)

```powershell
.\rla.exe -d "<DIRECTORY_WITH_HIVES>" --out <CLEAN_OUTPUT_DIRECTORY>
# Critical Note (Fact): If a hive is "dirty," you must use rla.exe first.
```

#### Recycle Bin (RBCmd)

```powershell
RBCmd.exe -d "<PATH_TO_RECYCLE_BIN>" --csv "<OUTPUT_DIRECTORY>" -q
# Path: C:\$Recycle.Bin
```

#### Pagefile & Memory Strings (bstrings)

```powershell
# Search Pagefile (C:\pagefile.sys)
bstrings.exe -f "<PATH_TO_PAGEFILE.SYS>" --qs "<MALICIOUS_DOMAIN>"
# Search Hiberfil (C:\hiberfil.sys)
bstrings.exe -f "<PATH_TO_HIBERFIL.SYS>" --qs "<MALICIOUS_DOMAIN>"
```

### 2.3 Browser Forensics (Hindsight)

```powershell
hindsight.exe -i "<PATH_TO_BROWSER_PROFILE>" -o "<OUTPUT_DIRECTORY>"
# Chrome/Edge: C:\Users\<USERNAME>\AppData\Local\<Browser>\User Data\Default
```

### 2.4 Registry Analysis (RegRipper)

```powershell
.\rip.exe -r "<PATH_TO_HIVE_FILE>" -p <PLUGIN_NAME>
```

## Phase 3: PowerShell & Advanced Event Log Hunting

**Focus:** Native Windows Event Log analysis and EQL.

### 3.1 Core Filtering Syntax (FilterHashtable)

```powershell
Get-WinEvent -FilterHashtable @{
    LogName   = '<LOG_NAME>';
    ID        = <EVENT_ID>;
    Level     = <1-5>;
    StartTime = (Get-Date).AddHours(-<HOURS>);
} -ErrorAction SilentlyContinue
```

**LogName Reference:** Security, System, Application, Microsoft-Windows-Sysmon/Operational, Microsoft-Windows-PowerShell/Operational.

### 3.2 String & Pattern Hunting (Client-Side)

```powershell
Get-WinEvent -FilterHashtable @{LogName='<LOG_NAME>'; StartTime=(Get-Date).AddDays(-<DAYS>)} | 
Where-Object { $_.Message -like "*<KEYWORD>*" } | 
Select-Object TimeCreated, Id, Message
```

### 3.3 Legacy: Filtering by Property Index (Quick Triage Only)

```powershell
Get-WinEvent -FilterHashtable @{LogName='<LOG_NAME>'; ID=<EVENT_ID>} | 
Where-Object { $_.Properties[<INDEX>].Value -eq <VALUE> }
```

**Index Discovery (The "Lost" Script):**
*If unsure of the property index ID, run this discovery command first:*

```powershell
$Event = Get-WinEvent -LogName <LOG_NAME> -Id <EVENT_ID> -MaxEvents 1
for ($i=0; $i -lt $Event.Properties.Count; $i++) {
    [PSCustomObject]@{
        Index = $i
        Value = $Event.Properties[$i].Value
    }
}
```

### 3.4 Offline Log Analysis (.evtx)
**Bulk Search in Directory:**

```powershell
Get-ChildItem "<DIRECTORY_PATH>\*.evtx" | ForEach-Object {
    $CurrentFile = $_.Name
    Get-WinEvent -Path $_.FullName -FilterXPath "*[System[(EventID=<EVENT_ID>)]]" -ErrorAction SilentlyContinue | 
    Select-Object @{Name='SourceFile'; Expression={$CurrentFile}}, TimeCreated, Id, MachineName, Message
} | Export-Csv "Forensic_Export.csv" -NoTypeInformation
```

### 3.5 XML Data Extraction (Advanced)

```powershell
$EvtxPath = "<PATH_TO_EVTX>"
Get-WinEvent -Path $EvtxPath -FilterHashtable @{ID=<EVENT_ID>} | ForEach-Object {
    $xml = [xml]$_.ToXml()
    $eventData = $xml.Event.EventData.Data
    [PSCustomObject]@{
        Time          = $_.TimeCreated
        TargetField   = $eventData | Where-Object {$_.Name -eq "<DATA_NAME>"} | Select-Object -ExpandProperty '#text'
    }
}
```

### 3.6 Advanced XPath Filtering (FilterXml)

```powershell
$XPathQuery = @"
<QueryList>
    <Query Id="0">
    <Select Path="<LOG_NAME>">
        *[System[(EventID=<EVENT_ID>)]] 
        and (*[EventData[Data='<VALUE_1>']] or *[EventData[Data='<VALUE_2>']])
    </Select>
    </Query>
</QueryList>
"@
```

### 3.7 Offline Threat Hunting (Chainsaw & Sigma)

```powershell
# Chainsaw Hunt
.\chainsaw hunt <PATH_TO_EVTX> -s <PATH_TO_SIGMA_RULE.yml> --mapping mappings\sigma-event-logs-all.yml
```

### 3.8 Advanced Offline Hunting with EQL (Event Query Language)
**Step 1: Convert EVTX to EQL-compatible JSON**

```powershell
Import-Module .\scrape-events.ps1
Get-WinEvent -Path "<PATH_TO_SYSMON_EVTX>" -Oldest | Get-EventProps | ConvertTo-Json | Out-File -Encoding ASCII eql-sysmon.json
```

**Step 2: Execute EQL Queries (e.g., T1055 Process Injection)**

```powershell
eql query -f eql-sysmon.json "sequence by ProcessGuid [process where EventId=1 and Image='*discord.exe'] [process where EventId=1 and ParentImage='*discord.exe' and dwCreationFlags='0x4']"
```
